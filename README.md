# CryptoBuddy 
*"Your First AI-Powered Financial Sidekick!"* 

## Overview
CryptoBuddy is a beginner-friendly, **rule-based chatbot** built in Python.  
It analyzes cryptocurrencies using simple **profitability** (price trend, market cap) and **sustainability** (energy use, eco-score) rules.  
The chatbot answers natural questions like *“Which crypto is trending up?”* or *“What’s the most sustainable coin?”* and provides advice with a built-in disclaimer.

This project was created as **Week 1 Assignment** for the PLP Academy AI/Chatbot module.

---

## Features
- Friendly personality 🤖  
- Predefined dataset (Bitcoin, Ethereum, Cardano) 📊  
- Simple rule-based logic (using `if-else`)  
- Provides advice on:
  - Which coins are trending  
  - Most sustainable crypto 🌱  
  - Long-term investment suggestions 🚀  
- Built-in disclaimer: *Not financial advice — always DYOR!*
